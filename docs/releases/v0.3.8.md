# v0.3.8 同步上游 v6.3.0

这版主要是跟进 `obra/superpowers` 的 `v6.3.0`。本仓库自己的安装方式和中文触发规则没有新增破坏性变化，重点是把上游 skill、插件 manifest、测试和文档同步到最新。

## 更新了什么

- vendored 上游 `obra/superpowers` 已从 `v6.1.1` 更新到 `v6.3.0`
- README 顶部的 vendored 版本号同步更新为 `v6.3.0`
- 保持现有 `Cline`、`Claude Code`、`Codex`、`Droid`、`OpenCode`、`CodeBuddy`、`ZCode` 安装入口不变

## 上游这次主要变了什么

- `v6.2.0` 调整了 `subagent-driven-development` 的工作区和 review-fix 循环，避免不同计划之间复用旧 ledger
- `v6.2.0` 把 TDD 的测试参考从 `testing-anti-patterns.md` 重写为 `writing-good-tests.md`
- `v6.2.0` 恢复 Gemini CLI 支持，并更新 Windows SessionStart hook 的执行方式
- `v6.3.0` 新增 Devin CLI、Hermes Agent、Grok Build CLI 相关支持
- `v6.3.0` 调整 brainstorming 的流程分级，小任务会更轻量，但仍会在实现前停下来等用户确认
- `v6.3.0` 继续优化 SDD、Codex 多代理等待、分支收尾和 Windows 相关说明
