# v0.3.9 同步上游 v6.4.2

这版跟进 `obra/superpowers` 的 `v6.4.2`。上游这次变化比前几次大：skill 数量从 14 个变成 15 个，还改了 `executing-plans`、`writing-plans`、OpenCode 和说明文件的组织方式。

## 这版更新了什么

- vendored 上游 `obra/superpowers` 已从 `v6.3.0` 更新到 `v6.4.2`
- README 顶部的同步版本号更新为 `v6.4.2`
- 新增上游 `diagnosing-superpowers` 的中文触发词，避免装上了但中文不容易触发
- 能力矩阵从 14 个 skill 更新为 15 个 skill，并补上 `diagnosing-superpowers` 的速查说明

## 上游主要变化

- 新增 `diagnosing-superpowers`，用于诊断 superpowers 会话里 skill 没触发、重复劳动、耗时或成本异常这类问题
- `executing-plans` 改成更完整的原生执行流程，不再只是很薄的提示
- `writing-plans` 收紧计划内容，少写实现全文，多记录接口、断言和验证命令
- 上游新增 OpenCode 2.0、Muse、Qwen Code 相关支持；本仓库这次新增的是 Qoder CN 目标，不把 Qwen Code 作为安装目标
- 上游删除根目录 `CLAUDE.md`，改以 `AGENTS.md` 作为贡献说明；本仓库 Claude Code 安装仍保留自己的托管说明段，不整文件覆盖用户配置

## 兼容性结论

- 现有 `Cline`、`Claude Code`、`Codex`、`Droid`、`OpenCode`、`CodeBuddy`、`ZCode` 安装入口保持不变
- 新增 `QoderCN` 目标，User 模式安装到 `~/.qoder-cn/skills`，Project 模式安装到 `<project>/.qoder/skills`
- 8 个目标的项目级 smoke 都应安装出 15 个 skill
- OpenCode 这次上游新增 V2 原生插件支持，但本仓库现有 OpenCode 适配仍按既有 `.config/opencode/skill` / `.opencode/skill` 路径验证

## 已验证

- PowerShell 公共测试通过
- 中文触发词映射检查通过：15 个 skill，缺失 0，多余 0
- ZCode 和 Qoder CN 单目标项目安装 smoke 通过，真实 `v6.4.2` 装出 15 个 skill
- `install-all.ps1 -Targets All` 项目级 smoke 通过，8 个目标都装出 15 个 skill
- 适配层 `git diff --check -- . ':(exclude)vendor/superpowers'` 通过；完整 diff 会报上游 vendored `CODE_OF_CONDUCT.md` 里的一个尾随空格，本仓库没有改写这份上游内容
