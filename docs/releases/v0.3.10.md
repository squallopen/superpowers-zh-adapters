# v0.3.10 同步上游 v7.0.0

这版跟进 `obra/superpowers` 的 `v7.0.0`。这次上游没有新增或删除 skill，还是 15 个；主要变化集中在 `brainstorming` 重写、Windows hook 修复、Antigravity 原生插件、Hermes skill 描述修复，以及几个 workflow 小修。

## 这版更新了什么

- vendored 上游 `obra/superpowers` 已从 `v6.4.2` 更新到 `v7.0.0`
- README 顶部的同步版本号更新为 `v7.0.0`
- 保持现有 8 个目标：`Cline`、`Claude Code`、`Codex`、`Droid`、`OpenCode`、`CodeBuddy`、`ZCode`、`Qoder CN`
- 修复刷新脚本对 annotated tag 的处理，像 `v7.0.0` 这种 tag 不再输出 “is not a commit” 这类误导提示，manifest 也会正确记录 `upstream_ref`

## 上游主要变化

- `brainstorming` 重写：更强调先弄清楚用户真实意图，再决定是直接做、小改动设计，还是写完整设计文档
- 新增 Antigravity Marketplace 原生 manifest；本仓库暂不新增 Antigravity 适配目标
- Windows hook 更稳：修复 PATH 异常、Git Bash / WSL 选择、hook exit code 透传等问题
- `executing-plans` 的 `task-done` 能记录“测试通过但没有输出”的情况
- `subagent-driven-development` 在 Windows 下的 plan marker 处理更稳
- Hermes 插件现在会把 skill frontmatter description 注册出去

## 兼容性结论

- skill 数量仍为 15，中文触发词映射无需增删
- 现有 8 个目标的安装路径和说明段策略保持不变
- `brainstorming` 的内部资源文件有变化，但我们的安装脚本复制整个 skill 目录，所以会自然带上新的 `builder-check-prompt.md`
- 上游新增的 Antigravity manifest 不影响当前 Windows PowerShell 安装链路；暂不把 Antigravity 加到本仓库的 `Targets`

## 已验证

- PowerShell 公共测试通过
- 新增 annotated tag 刷新回归测试通过
- 中文触发词映射检查通过：15 个 skill，缺失 0，多余 0
- `install-all.ps1 -Targets All` 项目级 smoke 通过，8 个目标都装出 15 个 skill
- 适配层 `git diff --check -- . ':(exclude)vendor/superpowers'` 通过
- 完整 diff check 只报上游 vendored `RELEASE-NOTES.md` 里的一个尾随空格，本仓库保留上游原样
